Projeto LDLanches

Descrição: Sistema de gestão para lanchonete delivery que centraliza pedidos, status, catálogo de produtos e monitoramento de temperatura dos freezers.


Tecnologias Utilizadas: Painel administrativo em Kotlin Multiplatform (KMP) com Compose, cardápio web consumindo APIs REST em Spring Boot e integração com dispositivo IoT ESP32 para leitura de temperatura.


Minha Participação: Atuei no desenvolvimento do front-end, criando o painel administrativo em KMP/Compose e a interface web do cardápio, incluindo a exibição dos dados de temperatura enviados pelo ESP32.

Clone do Instagram

Descrição: Aplicação mobile que simula as funcionalidades principais do Instagram, incluindo feed de postagens, stories, perfis de usuário, comentários e sistema de autenticação, com todos os dados salvos localmente no dispositivo.


Tecnologias Utilizadas: O app foi desenvolvido em React Native com Expo. Para o armazenamento de dados, foi utilizado o banco de dados local SQLite, gerenciado através do `expo-sqlite`.


Minha Participação: Desenvolvi a aplicação do início ao fim, cuidando tanto da criação das interfaces e componentes em React Native quanto da implementação da base de dados com SQLite para gerenciar usuários, posts e stories de forma local.

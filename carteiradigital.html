Projeto Carteira Digital

Descrição: Aplicativo de gestão financeira que integra a IA Generativa do Gemini para criar lições de aprendizado personalizadas. Além de gerenciar transações e metas, o app oferece uma área de educação financeira com conteúdo gerado dinamicamente pela IA.


Tecnologias Utilizadas: Desenvolvido em React Native e TypeScript, com Firebase (Auth, Firestore, Functions) para o backend. A integração com a IA é feita através de chamadas para a API do Google Gemini.


Minha Participação: Como desenvolvedor full-stack, fui responsável por toda a aplicação, desde a interface em React Native até a arquitetura do backend no Firebase. Destaque para a implementação da integração com a API do Gemini, criando a funcionalidade de geração de lições financeiras por IA.

Projeto Barbearia

Descrição: Sistema de gerenciamento desenvolvido para otimizar a rotina de uma barbearia, permitindo o agendamento de horários, cadastro de clientes e controle de serviços prestados. O projeto visa facilitar a administração do negócio e melhorar a experiência do cliente.


Tecnologias Utilizadas: O back-end da aplicação foi desenvolvido em PHP, conectando-se a um banco de dados MySQL para toda a gestão de dados. O front-end foi construído com HTML, CSS e JavaScript para criar a interface de usuário e a interatividade.


Minha Participação: Fui responsável pela arquitetura e desenvolvimento do banco de dados, criando todo o script SQL para a comunicação com o backend. Além disso, participei ativamente da fase de planejamento, elaborando diagramas de entidade-relacionamento e definindo parte das regras de negócio do sistema.

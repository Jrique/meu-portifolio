Projeto Quanto Cairá?

Descrição: Uma calculadora de salário líquido desenvolvida para que o usuário possa simular de forma rápida e visual o valor que receberá após os descontos obrigatórios, como INSS e Imposto de Renda, além de Vale Transporte e outros descontos adicionais.


Tecnologias Utilizadas: O projeto é uma aplicação web de front-end pura, construída com HTML5, CSS3 e JavaScript. Não utiliza frameworks, focando na manipulação direta do DOM para os cálculos e exibição de resultados.


Minha Participação: Desenvolvi o projeto do início ao fim, sendo responsável pela criação da interface com HTML/CSS e, principalmente, pela implementação de toda a lógica de cálculo em JavaScript, incluindo as regras de faixas de desconto do INSS e IRRF.
